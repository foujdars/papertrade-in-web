# PaperTrade reliability audit — 11 October 2026 IST

Base: `origin/main` at `9db21bb`. Changes are isolated on
`codex/bug-audit-20261010`; no production configuration, stored user data,
Supabase migrations, or deployment was changed.

## Fixed

- **Trade notification opt-out:** Indian technical alerts and user-created
  global alerts were checking pause dates but not the device's `trades`
  preference. Both dispatchers now skip opted-out devices. Trigger history is
  still recorded, and opted-out notifications are not queued for later replay.
  The independent EMA notification categories retain their existing settings.
- **Stalled exchange-session checks:** a request with no response left the
  pending flag set indefinitely. NSE/MCX session requests now have a 12-second
  deadline, allowing periodic and reconnect checks to recover. Failed checks
  still disable trading safely rather than guessing that the exchange is open.
- **Home derivatives refresh:** GIFT, VIX, expiry, option-chain and catalogue
  requests now have deadlines. Quotes/options refresh immediately when the app
  becomes visible or the network reconnects. Cleanup removes listeners and
  aborts work. An invalid VIX timestamp no longer throws from refresh.
- **Entry-study VWAP:** missing volume was replaced with `1`, producing a
  fabricated equal-weight contribution. Zero-volume candles now add nothing;
  missing/invalid volume leaves VWAP unavailable for the remainder of that
  session, resetting on the next day. Intraday VWAP-filtered entries cannot
  pass without VWAP; price-only setups remain available when that filter is off.
- **Test isolation:** restored missing mock exports and the renamed chart-key
  validator. The technical alert suite no longer runs independent default EMA
  dispatchers against external market services. Updated the price-alert
  assertion for the current title-only notification format.

## Verification

- `npm run test:reliability`: 26 tests passed.
- Expanded targeted run covering the above plus paper bots, Indian/global

- Full `node --experimental-strip-types --test tests/*.test.mjs` run:
  625 passed, 14 failed, 2 skipped (641 total). No new failing test appeared.

The remaining failures were present before this patch. They include source
assertions and component harnesses that no longer match the latest UI, and
generic indicator assertions that need separate review of sparse signal plots,
forming candles and latest-setup projections. They were not disabled or relaxed
as part of this fix.

Remaining failing suites: `bar-replay`, `compact-workspaces`, `ipo-directory`, `motion`,
`rendered-html`, and `study-calculations`. The optional database tests were
skipped because their PGlite dependency is not installed. The repository-wide
lint baseline also has existing errors beyond the changed files.

Browser tests were attempted but Chromium is not installed in this environment;
the attempted browser download failed. Consequently mobile layout, native
Android Back, actual push receipt and live closed-app execution are **not**
claimed verified by this audit. All new regression tests use controlled local
responses and do not place orders or send notifications.
